# pip 约束文件 —— 等价于 pyproject.toml 里的 [tool.uv] override-dependencies。
#
# 用法：pip install -c scripts/pip-constraints.txt ...
#
# 注意 uv 的 override 和 pip 的 constraint 语义并不完全相同：
#   * uv override  = 强制改写依赖声明，即使和上游声明冲突也照改。
#   * pip constraint = 只能在候选版本里做「收窄」，和上游声明冲突时 pip 会直接报错，
#     不会帮你改写。
# 因此这里只保留能用 constraint 表达的部分。如果将来某个上游包把版本上限压到
# 这里的下限以下，pip 会解析失败 —— 那时需要在下面追加一条精确 pin（参考
# langchain-litellm 那条的做法），而不是指望 pip 自动覆盖。
#
# 与 pyproject.toml [tool.uv] override-dependencies 保持同步。
